# LA😂PRINT

**See what’s moving. Understand why. Trade when you’re ready.**

Discovery-first Solana market intelligence — not a dashboard, not a forced wallet app.

## Quick start

Open `index.html` in any modern browser (no build required).

```bash
python3 -m http.server 8080
# or
npx serve .
```

## Product loop

```
Discover → See something moving → Open token → Understand market
  → Check flow → Social signals → On-chain → Timeline
  → Watch or Trade → Monitor → Autopilot → Exit → Discover again
```

## What’s included

| Screen | Notes |
|--------|--------|
| Landing | Hero + live market preview |
| Discover | Trending / Moving / New / Volume |
| Search | `/` shortcut · symbols, names, contracts |
| Token | Snapshot, flow, why moving, social, on-chain, timeline, contract, holders |
| Watch | Local persistence, no wallet |
| Trade | Wallet gate → form → review → position |
| Position | PnL · sell · autopilot |
| Autopilot | Spot config → live monitor |
| Wallet | Public inspection only |

## Rules

- Explore without connecting a wallet
- Wallet only for Trade / Autopilot
- Demo data is labeled — production uses live APIs only
- Social ≠ on-chain; no unsupported “influencer bought” claims
- Unavailable data is shown as unavailable
- No fake charts, SAFE badges, or trade-success states
