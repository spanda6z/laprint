# Full demo

The complete interactive product lives in the local workspace:

`laprint-demo/index.html`

Open it in a browser for the full flow:

- Landing + Discover (6 tokens)
- Search (`/` shortcut)
- Token intelligence page
- Watchlist with toasts
- Trade → Review → Position → Exit
- Autopilot (spot config + monitor)
- Public wallet view

GitHub `index.html` may be a lighter snapshot due to API size limits. Prefer the local file for the complete experience.
