# Security policy

## Supported versions

| Version | Supported |
|---------|----------|
| 0.x (prototype) | Best-effort |
| Production releases | To be defined at public beta |

## Reporting a vulnerability

Please **do not** file public GitHub issues for security vulnerabilities involving:

- Wallet connection or transaction signing  
- Swap routing or slippage handling  
- API key exposure  
- XSS / injection in market or social rendering  

Contact the repository owner privately via GitHub security advisories:

https://github.com/spanda6z/laprint/security/advisories/new

Include:

- Description of the issue  
- Steps to reproduce  
- Potential impact  
- Suggested fix if available  

We will acknowledge reports as quickly as practical and coordinate disclosure.

## Safe harbor

We will not pursue legal action against researchers who:

- Act in good faith  
- Avoid privacy violations and service degradation  
- Give reasonable time to remediate before public disclosure
