# Product specification

## Promise

> See what’s moving.  
> Understand why.  
> Trade when you’re ready.

## Positioning

LA😂PRINT is **discovery-first Solana market intelligence**.

It is not:

- A generic crypto admin dashboard  
- A wallet-gated exploration app  
- A social hype terminal that invents causation  

It is:

- A live market surface you can browse freely  
- An investigation workspace for any token  
- A path to trade and automate only after understanding  

## Non-negotiable rules

1. **Explore without a wallet.** Connection is required only for Trade, Fund, Open Position, or Live Autopilot.
2. **Never fabricate** market data, charts, social activity, holders, wallet activity, or trade results.
3. **Show unavailability clearly** when data is missing.
4. **Keep X/social and on-chain as separate evidence.** Do not merge into unsupported claims.
5. **Never claim** an influencer bought, launched, or caused a move without verified evidence.
6. **No fake “SAFE” badges** or invented security scores.
7. **Discovery is home.** There is no primary “Dashboard” destination.
8. **Premium, fast, minimal, market-focused** UI — not a settings panel with fifty buttons.

## Primary question

> Can the user understand what is happening with a token within about **10 seconds**?

Every card, section, and signal must serve that.

## Screens

| Screen | Purpose |
|--------|--------|
| Landing | Promise + path into market / autopilot |
| Discover | What’s moving (Trending, Moving, New, Volume) |
| Search | Tokens, contracts, creators |
| Token | Intelligence workspace (flow, social, on-chain, timeline) |
| Watch | Local watchlist, no wallet |
| Trade | Wallet-gated execution path |
| Position | Live PnL, exit, enable autopilot |
| Autopilot | User-configured monitoring (spot first) |
| History | Realized results from verified execution |
| Wallet | Public wallet inspection |

## Token page hierarchy (10-second design)

1. Price + 1H change + 5M buy flow (hero)  
2. Evidence chips (flow / social / on-chain status)  
3. Market metrics  
4. Market flow windows  
5. Why it’s moving (facts only)  
6. Social signals (separate)  
7. On-chain notes (separate)  
8. Event timeline (time-aligned, non-causal)  
9. Contract & holders (secondary, collapsible)  

## Language

Prefer:

- “mentioned”  
- “contract detected in post”  
- “associated wallet activity”  
- “on-chain activity near the mention”  
- “time-aligned market observations”  

Avoid unless verified:

- “influencer bought”  
- “influencer launched”  
- “influencer pumped”  

## Success metric (product)

A new user can:

1. Open Discover without connecting  
2. Identify a mover in under 5 seconds  
3. Open the token and state *what moved* and *what evidence exists* in under 10 seconds  
4. Watch without a wallet  
5. Connect only when they decide to trade
